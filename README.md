### 🧼 MVP Detailing – Website
## 🇬🇧 English

A responsive, modern website for MVP Detailing, showcasing services, pricing, and contact information.

### 🌐 Tech Stack

- Next.js (React)
- TypeScript
- Tailwind CSS
- Vercel (deployment)

### 📄 Features

- Responsive design for mobile and desktop
- Service descriptions and pricing
- Contact form with validation
- SEO optimization
- Fast loading and optimized assets

### 🚧 Status

- Initial version deployed
- Open to improvements and feedback

### 📂 Project Structure

- `/pages` – Main routes
- `/components` – Reusable UI components
- `/public` – Static assets
- `/styles` – Global styles
